How to use GradeHawk

Back to search

GradeHawk helps you search historical University of Iowa course grade distributions by course, title, instructor, and semester.

Search for a course

Enter a course code, course title, or instructor name. Search terms are combined with AND by default.

  • CS:2230 finds a specific course.
  • data structures finds results containing both terms.
  • CS OR MATH finds results matching either subject.
  • data -lab includes “data” and excludes “lab”.
  • "linear algebra" searches for an exact phrase.
  • CS:4* matches course codes beginning with CS:4.

Filter the results

Semester
Show results from one semester or all available semesters.
Results per page
Choose how many results appear at once. Mobile starts with 10.
Group sections
Combine sections of the same course within each semester.
Group semesters
Combine the course’s results across semesters. This also enables Group sections.

Sort results

Results default to semester newest first. Select a table heading to sort by that column. Select it again to reverse the order, and a third time to return to the default semester-newest-first order.

View course details

Select a course code to open its grade distribution. The details page includes a summary, histogram, grade-count table, section selector, and semester selector.

Use All sections or All semesters to combine distributions across the selected scope.

On a course details page, All sections for this instructor combines every section taught by the selected instructor in the selected semester.

Share a search

Search settings are saved in the page URL. Copy the URL from your browser to share the same query, filters, grouping settings, and sort order with someone else.
